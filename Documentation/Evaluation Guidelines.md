# AI Evaluation Guidelines

## 1. Purpose

The purpose of AI evaluation is to assess whether generated
outputs satisfy user instructions while maintaining visual
quality, accuracy, and consistency.

Human evaluation helps identify weaknesses that automated
metrics may not fully capture.

## 2. General Evaluation Principles

### Understand the Prompt
- Read the complete user prompt before evaluating outputs.
- Identify the requested objects, actions, environment, and style.
- Pay attention to specific visual requirements.

### Evaluate Independently
- Examine each output individually before comparing them.
- Avoid making decisions based solely on personal preferences.
- Focus on observable evidence.

### Use Consistent Criteria
- Apply the same evaluation dimensions to all outputs.
- Distinguish instruction-following issues from visual defects.
- Avoid penalizing an image for details that were not requested.

### Provide Evidence-Based Feedback
- Identify specific strengths and weaknesses.
- Explain why one output performs better than another.
- Avoid generic or unsupported comments.

## 3. Comparative Evaluation

When comparing two AI-generated images:

- Review Image A and Image B separately.
- Compare their alignment with the original prompt.
- Examine visual quality and generation artifacts.
- Identify correctness issues.
- Determine which output better satisfies the requested result.

## 4. Rating Approach

A five-level comparative rating scale can be used:

| Rating | Description |
|--------|-------------|
| A Much Better | Image A is significantly stronger |
| A Slightly Better | Image A performs somewhat better |
| Tie | Both outputs are comparable |
| B Slightly Better | Image B performs somewhat better |
| B Much Better | Image B is significantly stronger |

Use a tie only when the outputs are genuinely comparable.

## 5. Feedback Guidelines

A good evaluation comment should:

- Mention both Image A and Image B.
- Identify specific visual evidence.
- Connect the observation to the original prompt.
- Explain the reason for the selected rating.
- Remain concise and objective.

## 6. Common Evaluation Mistakes

- Relying entirely on subjective preferences.
- Ignoring important prompt requirements.
- Confusing artistic style with AI-generated artifacts.
- Overlooking distorted objects or inconsistent details.
- Providing generic feedback without visual evidence.
- Repeatedly assigning ties when meaningful differences exist.

## 7. Expected Outcome

Consistent evaluation produces structured feedback that
helps identify output weaknesses, assess model quality,
and support improvements in AI-generated content.
