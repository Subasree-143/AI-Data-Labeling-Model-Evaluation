# Instruction Following Evaluation

## 1. Overview

Instruction following measures how accurately an AI-generated
image reflects the requirements specified in a user prompt.

The objective is to determine whether the generated output
successfully translates textual instructions into visual content.

## 2. Core Evaluation Components

### Subject Alignment
- Does the image contain the requested subject?
- Are the main objects represented correctly?
- Are the required subjects clearly visible?

### Style Alignment
- Does the image follow the requested artistic style?
- Are specified visual references reflected?
- Does the output maintain the requested aesthetic?

### Composition Alignment
- Are objects positioned as requested?
- Does the image follow the requested layout?
- Are foreground and background elements appropriate?

### Action and Interaction
- Are requested actions represented correctly?
- Are interactions between subjects accurate?
- Are important relationships between objects maintained?

### Environmental Requirements
- Does the background match the description?
- Are the requested surroundings included?
- Are lighting and atmosphere consistent with the prompt?

## 3. Evaluation Methodology

1. Extract the key requirements from the prompt.
2. Identify the essential visual elements.
3. Compare each requirement against the generated output.
4. Record fulfilled and unfulfilled requirements.
5. Compare the overall instruction adherence of both images.

## 4. Common Instruction-Following Issues

| Issue | Example |
|-------|---------|
| Missing subject | Requested object is absent |
| Incorrect style | Requested watercolor, generated photorealism |
| Wrong composition | Subject placed incorrectly |
| Missing detail | Important requested element omitted |
| Incorrect action | Subject performs a different action |
| Background mismatch | Requested setting is not represented |

## 5. Important Distinction

Instruction following and visual quality should be
evaluated separately.

An image can have excellent visual quality but fail
to follow the requested style or composition.

Similarly, an image can follow the prompt accurately
while containing minor technical imperfections.

## 6. Expected Outcome

The evaluation should determine how effectively the
AI system translates user instructions into the
intended visual output.
