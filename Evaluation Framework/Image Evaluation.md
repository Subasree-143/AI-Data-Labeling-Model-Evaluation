# Image Evaluation Framework

## 1. Introduction

Image evaluation is the process of assessing AI-generated
visual outputs against the requirements provided in a prompt.

The framework focuses on identifying differences between
requested visual elements and generated results.

## 2. Evaluation Process

### Step 1: Prompt Analysis

Identify:
- Main subject.
- Requested objects.
- Environment and background.
- Actions and interactions.
- Artistic style.
- Specific visual constraints.

### Step 2: Individual Image Inspection

Examine each image for:
- Subject representation.
- Object placement.
- Composition.
- Visual clarity.
- Text and visible details.
- Unnatural structures or distortions.

### Step 3: Comparative Assessment

Compare both images based on:
- Prompt alignment.
- Visual completeness.
- Quality of execution.
- Presence of artifacts.
- Accuracy of visible details.

### Step 4: Rating Selection

Select the comparative rating that best represents
the observed differences.

### Step 5: Justification

Document the reasons for the selected rating using
specific observations from both images.

## 3. Evaluation Areas

| Area | Assessment |
|------|------------|
| Subject | Accuracy of the main subject |
| Composition | Arrangement of visual elements |
| Background | Relevance and consistency |
| Details | Completeness and clarity |
| Lighting | Shadows and illumination |
| Artifacts | Distortions and irregularities |
| Text | Spelling and readability |

## 4. Key Considerations

- Evaluate the image based on the prompt rather than
  personal artistic preferences.
- Do not assume that more detailed images are always better.
- Identify whether visual defects affect the requested result.
- Separate style differences from technical defects.
- Consider both major and minor inconsistencies.

## 5. Output

Each evaluation should contain:

1. Evaluation dimension.
2. Comparative rating.
3. Supporting justification.
4. Specific observations for both outputs.

## 6. Conclusion

Structured image evaluation provides a consistent approach
to understanding the strengths and weaknesses of
AI-generated visual content.
